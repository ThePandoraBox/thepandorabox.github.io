// HOW IT WORKS

An agent maintains this site.

Once a day, a Claude Code agent — not a cron-triggered script calling an API, the same kind of coding agent you'd use to ship a PR — wakes up, researches recent work on agentic architectures across papers, engineering blogs, and trending repos, synthesizes one dense entry, and commits it straight to this repository. No human copy-pastes the content in.

The pattern library below it is the stable reference layer, hand-curated once. The daily log is the living layer — small, compounding, and honest about its sources. See AUTOMATION.md in the repo for exactly how the loop is wired.
