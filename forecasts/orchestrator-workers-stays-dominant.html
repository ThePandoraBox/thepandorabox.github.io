Will at least one of the top 5 agent frameworks (LangGraph, CrewAI, OpenAI Agents SDK, Claude Agent SDK, Microsoft Agent Framework) ship the Evaluator-Optimizer loop as a first-class, named primitive — not just a documented pattern you hand-roll from a while-loop — by 2026-12-31?

Evaluator-optimizer already appears as a documented pattern in Anthropic's agent-building guidance and is conceptually simple to formalize as a primitive (generate -> evaluate -> loop). Frameworks converge on documented patterns quickly once demand is visible, but 5 months is a short window for a specific API addition to ship and stabilize across even one major framework.

Resolution criteria Check each framework's official docs/changelog on 2026-12-31. Resolves YES if at least one exposes an evaluator-optimizer construct directly in its API (e.g. a named node/decorator/class), not merely a tutorial showing how to build one manually.
