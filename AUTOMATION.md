# How the daily automation works

The daily entry isn't generated by a GitHub Actions job calling an LLM API.
It's produced by a **Claude Code agent** — the same kind of coding agent
used to develop this repo — running on a schedule via a Claude Code Routine
(a scheduled trigger), doing real research and a real commit each day.

## The loop

1. **Trigger fires daily** (see the Routine configured for this repo — list
   it with the `claude-code-remote` MCP server's `list_triggers` tool, or in
   the Claude Code web UI under this session's scheduled tasks).
2. **A fresh Claude Code session starts** with a standing instruction (see
   below) and access to this repository plus web search/fetch.
3. **The agent researches** recent agentic-architecture material: arXiv
   papers, engineering blogs (Anthropic, OpenAI, LangChain, and similar),
   and GitHub trending repos tagged around agents/LLM orchestration.
4. **It synthesizes one entry** — not a link dump, an actual distillation —
   following the schema in `data/daily/TEMPLATE.json`, writes
   `data/daily/YYYY-MM-DD.json`, and adds the corresponding row to
   `data/daily/index.json`.
5. **It commits and pushes directly to `master`.** The
   `validate-content.yml` workflow acts as a mechanical evaluator
   (schema + consistency check) on every push that touches `data/daily/`.
6. GitHub Pages serves the update automatically — no deploy step.

## Why direct-to-master

The content is low-stakes (a research digest, not user data or
infrastructure), every change is a single additive JSON file plus one
index row, and git makes any bad entry trivial to revert. That tradeoff —
skip a review queue in exchange for the pipeline actually being autonomous
— was a deliberate choice, not an oversight. If that stops being the right
call (e.g. entries need editorial review before publishing), switch the
final step to opening a PR instead of pushing straight to `master`.

## Standing instruction given to the daily agent

> Research the most interesting recent development in agentic AI
> architecture from arXiv, engineering blogs, or trending GitHub repos.
> Pick one specific, non-generic angle — not "AI agents are advancing."
> Write a new entry at `data/daily/YYYY-MM-DD.json` following the schema
> in `data/daily/TEMPLATE.json` exactly, using today's date. Only cite
> sources you actually fetched and read. Add a matching row to
> `data/daily/index.json`. Commit with a clear message and push to
> `master`.

## Adjusting the schedule

The Routine's cron expression, prompt, and enabled state can be changed
with the `claude-code-remote` MCP server's `update_trigger` tool (or
disabled entirely with `enabled: false`) without touching this repo.
